Bang Rizky Dimsum
Website sederhana untuk memperkenalkan UMKM Bang Rizky Dimsum, yang berlokasi di kawasan Gunung Putri, Kabupaten Bogor.

Website ini dibuat menggunakan HTML, CSS, dan JavaScript dalam satu file mandiri.
Fitur
- Tampilan responsif untuk desktop dan perangkat mobile.
- Pengenalan Bang Rizky Dimsum.
- Informasi tiga varian dimsum: Mentai, Keju, dan BBQ Mayo.
- Tombol pemesanan yang mengarah ke WhatsApp.
- Informasi lokasi dan tautan pencarian Google Maps.
- Animasi sederhana saat bagian halaman muncul ketika di-scroll.
- Logo tertanam langsung di dalam file HTML, sehingga tidak memerlukan file gambar terpisah.
Teknologi
- HTML5
- CSS3
- JavaScript
Tidak memerlukan framework, package manager, atau proses instalasi.
Menjalankan Secara Lokal
1. Download atau clone repository ini.
2. Buka file index.html menggunakan browser seperti Google Chrome atau Microsoft Edge.
Menayangkan dengan GitHub Pages
1. Upload index.html dan README.md ke repository GitHub.
2. Buka Settings pada repository.
3. Pilih Pages.
4. Pada bagian Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder / (root).
6. Klik Save dan tunggu proses deployment selesai.
7. GitHub akan menampilkan alamat website pada bagian GitHub Pages.
