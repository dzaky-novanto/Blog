# Bang Rizky Dimsum

Website pengenalan UMKM Bang Rizky Dimsum di kawasan Gunung Putri, Kabupaten Bogor.

## Isi repository
- `index.html` — halaman utama website.
- `logo.webp` — logo yang digunakan pada halaman.
- `README.md` — dokumentasi proyek.

## Teknologi
HTML5, CSS3, dan JavaScript. Tidak membutuhkan framework atau proses build.

## Menjalankan lokal
Pastikan `index.html` dan `logo.webp` berada dalam folder yang sama, lalu buka `index.html` melalui browser.

## Deploy ke Vercel
Import repository ini ke Vercel dengan pengaturan: Framework Preset `Other`, Root Directory `./`, Build Command kosong, Output Directory `.`. Pastikan `index.html` dan `logo.webp` berada di root repository.
